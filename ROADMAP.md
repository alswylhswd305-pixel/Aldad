# Aldad Roadmap / خارطة طريق الضاد

## Current: 1.9.17 Preview

Priority is stability, not adding more syntax.

Before the next Stable release:

- validate the IDE on Windows 11 with real interactive use;
- validate the VS Code extension inside VS Code on Windows;
- fix reproducible engine bugs and add regression tests;
- keep `ثم`, `كم`, `احسب`, `كمل`, conditions, loops, and contextual values predictable;
- keep execution offline and deterministic;
- avoid adding commands unless an existing rule cannot express the required behavior clearly.

A future version number must represent real code changes. The project should not rename 1.9.17 to 1.9.19 without implementing and testing 1.9.19 changes.
